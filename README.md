# At_Home_labs
Collection of labs that can be done at home both locally or virtually.

These labs were designed using a "Human-in-the-Loop" approach. Google Gemini was utilized as a collaborator to help architect the modular shell scripts and help troubleshoot possible mounting issues. All logic was manually tested, debugged, and verified within a virtual Parrot OS environment to ensure accuracy.

File Nomenclature: file locations and names within these scripts are generic, feel free to label/mount in the way that best suits you.

Have fun!
